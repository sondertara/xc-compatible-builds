**推荐：安装到官方同款目录**

```bash
tar -xzf ThinkRail-{{VERSION}}-linux-<arch>-installer.tar.gz
./installer
```

安装后会写入：

- `~/.local/share/ai.thinkrail.app/stable/app`
- `~/.local/share/applications/ThinkRail.desktop`
- `~/.local/share/ai.thinkrail.app/stable/uninstall`

**便携运行（不写桌面项）**

```bash
tar -xzf ThinkRail-{{VERSION}}-linux-<arch>-kylin.tar.gz
./ThinkRail/bin/launcher
```
